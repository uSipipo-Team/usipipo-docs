# 🎨 Logo Assets uSipipo

> Logotipos, variaciones y guías de uso de marca

---

## 📐 Visión General

El logo de uSipipo combina elementos **cyberpunk** (neón, tecnología) con simbolismo de **privacidad** y **conectividad**. Diseñado para ser reconocible en cualquier tamaño y contexto.

---

## 🎯 Concepto del Logo

### **Elementos Principales**

1. **Escudo/Protector** - Simboliza privacidad y seguridad
2. **Relámpago/Conexión** - Representa velocidad y conectividad VPN
3. **Neon Glow** - Estética cyberpunk, tecnología futurista
4. **Tipografía Mono** - JetBrains Mono, evoca código/terminal

## 🚫 Uso Incorrecto

### **❌ No Hacer**

```
❌ No estirar o distorsionar
   [🛡️⚡] → [🛡️⚡ elongado]

❌ No cambiar colores arbitrariamente
   [🛡️⚡ cyan] → [🛡️⚡ verde]

❌ No agregar efectos no aprobados
   [🛡️⚡] → [🛡️⚡ con sombra 3D]

❌ No rotar
   [🛡️⚡] → [🛡️⚡ 45°]

❌ No poner sobre fondos que reduzcan legibilidad
   [🛡️⚡ sobre imagen busy]

❌ No usar versiones pixeladas
   [🛡️⚡ baja resolución]

❌ No modificar elementos
   [🛡️⚡] → [🛡️ sin relámpago]

❌ No agregar texto no autorizado
   [🛡️⚡ uSipipo "la mejor"]
```

## 📐 Construcción del Logo

### **Grid System**

```
┌─────────────────────────────────┐
│  ┌───┬───┬───┬───┬───┬───┐     │
│  │   │   │   │   │   │   │     │
│  ├───┼───┼───┼───┼───┼───┤     │
│  │   │   │ 🛡️  │   │   │     │
│  ├───┼───┼───┼───┼───┼───┤     │
│  │   │   │ ⚡  │   │   │     │
│  ├───┼───┼───┼───┼───┼───┤     │
│  │   │ u │ S │ i │ p │ o │     │
│  └───┴───┴───┴───┴───┴───┘     │
└─────────────────────────────────┘
```

**Proporciones:**
- Icon: 1:1 (cuadrado)
- Wordmark height: 1/3 de icon height
- Espacio entre icon y wordmark: 1/2 de icon width

---

### **Tipografía del Wordmark**

```
Fuente: JetBrains Mono
Peso: 600 (SemiBold)
Tracking: -0.02em
Leading: 1.2
```

**Kerning específico:**
- `uS`: -20 units
- `Si`: 0 units
- `ip`: -10 units
- `po`: -10 units
