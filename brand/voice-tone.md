# 📣 Voz y Tono uSipipo

> Guía de comunicación y estilo para el ecosistema uSipipo

---

## 🎯 Visión General

La voz de uSipipo es **tecnológica pero accesible**, **directa sin ser fría**, y **empoderadora sin ser agresiva**. Hablamos como un experto en privacidad que quiere ayudarte, no como un vendedor.

## 📐 Estructura de Mensajes

### **Fórmula de Value Proposition**

```
[Qué es] + [Para quién] + [Beneficio principal] + [Diferenciador]

Ejemplo:
"uSipipo es una VPN (qué) 
para Latinos (para quién) 
que quieren privacidad digital (beneficio) 
sin configuraciones complejas (diferenciador)"
```

---

### **Fórmula de Feature**

```
[Nombre] + [Qué hace] + [Por qué importa]

Ejemplo:
"Setup en 60 segundos (nombre)
Te conecta automáticamente (qué hace)
Para que navegues seguro sin perder tiempo (por qué importa)"
```

---

### **Fórmula de Error**

```
[Qué pasó] + [Por qué] + [Qué hacer]

Ejemplo:
"Tu conexión expiró (qué pasó)
Porque se acabó tu data (por qué)
Recarga para continuar (qué hacer)"
```

### **Formato de Texto**

**Negritas:** Para énfasis en palabras clave
```
✅ "Tu privacidad es **tuya**. No la regales."
❌ "Tu privacidad es **tuya y muy importante**."
```

**Cursivas:** Para términos técnicos o extranjeros
```
✅ "El *setup* toma menos de 1 minuto"
✅ "Usa el protocolo *WireGuard*"
```

**Code inline:** Para comandos, URLs, valores técnicos
```
✅ "Usa `/start` para comenzar"
✅ "Visita `usipipo.com`"
✅ "Token: `abc123...`"
```

## 🚫 Anti-patrones de Comunicación

### **❌ No Hacer**

```
❌ "Estimado cliente, le informamos que su servicio ha sido activado"
   (Muy corporativo, distante)

❌ "¡OFERTA LIMITADA! ¡COMPRA AHORA O TE LO PIERDES!"
   (Muy agresivo, spammy)

❌ "Nuestra VPN utiliza tecnología de encriptación AES-256-GCM con 
    handshake de curva elíptica y perfect forward secrecy"
   (Muy técnico, abrumador)

❌ "Somos la mejor VPN del mercado con 100% de uptime garantizado"
   (Promesas excesivas, poco creíble)

❌ "La privacidad es importante. Usa VPN."
   (Muy vago, sin personalidad)
```

### **✅ Hacer**

```
✅ "Tu VPN está lista. Conéctate y navega seguro."
   (Directo, claro, útil)

✅ "Plan Premium: 50 GB por $50 USD/mes. Sin letras chicas."
   (Claro, transparente)

✅ "Tus datos viajan cifrados con WireGuard. Nadie puede espiarlos."
   (Técnico pero accesible)

✅ "99.9% uptime. Cuando nos caemos, te avisamos."
   (Honesto, transparente)

✅ "No guardamos logs. Ni de conexión, ni de tráfico, ni de DNS. 
    Tu privacidad es tuya."
   (Específico, con personalidad)
```
